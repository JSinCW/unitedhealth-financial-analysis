# UnitedHealth Group Financial Forecasting & S&P 500 Analysis

## Project Overview

This project evaluates the financial performance and market risk of **UnitedHealth Group (UNH)** using historical financial and stock-market data.

The analysis combines stock-return analysis, beta estimation, capital-structure information, and financial forecasting in Excel to assess the company's risk and develop a three-year pro forma financial outlook.

## Objectives

- Compare UnitedHealth Group stock returns with the broader S&P 500 market
- Estimate the company's market risk using beta
- Examine debt, equity, and tax-related capital structure inputs
- Analyze historical financial performance
- Develop a three-year pro forma income statement
- Evaluate expected revenue, costs, operating earnings, and net income

## Tools

- Microsoft Excel
- Financial Statement Analysis
- Market Return Analysis
- Beta Analysis
- Financial Forecasting
- Pro Forma Modeling

## Market Risk Analysis

Historical UnitedHealth Group returns were compared with S&P 500 benchmark returns.

The analysis produced an estimated:

- **Equity Beta: ~0.58**
- **Asset Beta: ~0.37**

These measures were used to evaluate UnitedHealth Group's sensitivity to broader market movements and consider the impact of its capital structure.

## Financial Forecasting

A three-year pro forma income statement was developed using historical financial information and a **13% revenue-growth assumption**.

Projected customer revenues were approximately:

- **Year 1: $415.3 billion**
- **Year 2: $469.3 billion**
- **Year 3: $530.3 billion**

The model also projected operating costs, earnings, and net income to evaluate future financial performance.

## Key Takeaways

- Combined market-based risk analysis with company financial information.
- Used historical performance to develop forward-looking financial projections.
- Applied beta and capital-structure concepts to evaluate financial risk.
- Built an Excel-based pro forma model to support business and financial decision-making.
